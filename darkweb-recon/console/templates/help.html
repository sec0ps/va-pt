how to use

A workspace holds watch terms. When you run a search, every enabled term is used two ways. Terms that carry a value are sent to Ahmia as the search query. Then every enabled term, including extract all terms, is run against the titles and snippets Ahmia returns, and anything that matches becomes a finding. Matching today covers the result title and snippet, not the full onion page.

Start here. You need at least one term with a value to pull pages. A term left blank is an extract all term, it does not run a search on its own, it only pulls data out of pages that your valued terms surface. Add a literal, domain, or email with a value to drive the search, then add blank extractors on top to enrich.

examples

a full name

type literal, term jane doe. Literal is a plain substring, so it also covers a name embedded in longer text.

a company or brand

type literal, term red cell security.

a domain

type domain, term redcellsecurity.org. Add a second term, type email with @redcellsecurity.org, to catch that domain's addresses in the results.

an email address

type email, term ceo@redcellsecurity.org for one address, or @redcellsecurity.org for the whole domain. Leave the term blank to harvest every address on the pages your other terms surface.

a phone number

There is no phone type. For a specific number use type literal with the number written the way it appears, for example +1 214 555 0100 or (214) 555-0100. Because formatting varies, add a type regex term to catch variants in the results, for example

\+?1?[\s.-]*\(?\d{3}\)?[\s.-]*\d{3}[\s.-]*\d{4}

Regex only matches pages your valued terms surface, it does not run a search on its own.

leaked credentials for a target

Use a valued term to surface pages, for example domain redcellsecurity.org, then add a blank credential term to pull user and password pairs out of those pages. Passwords are masked by default.

crypto or card exposure

Add blank btc, eth, or card terms, paired with a valued term so pages get pulled. Card numbers are validated and masked.

notes

Credential and card values are masked where they are stored. They can be unmasked with the CREDENTIAL_MASK setting if you have a reason.

Matching runs on titles and snippets for now. Deep matching against full onion pages is planned.

After a run, hits appear in findings with a status of new. Confirm or dismiss each to triage.
